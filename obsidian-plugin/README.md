# 多平台投稿助手（Obsidian 本地插件）

在 Obsidian 打开一篇 Markdown 笔记后，点击左侧发送图标，或执行“生成并自动填充全部平台”。插件会生成投稿包、打开五个平台创作页，Edge 扩展会在编辑器出现后自动填写。命令“为当前笔记生成多平台投稿包”仍保留为只生成文件的备用入口。

投稿包位于 `10-准备发布/投稿包/`，其中包含：

- `公众号.html`：浏览器打开、复制正文到公众号，保留基础排版。
- `知乎.md`、`小红书.md`、`B站专栏.md`、`CSDN.md`：各平台的可复制 Markdown。
- `投稿助手.html`：一个本地页面，点击平台按钮会复制正文并打开其官方创作入口。
- `发布清单.md`：发布前检查封面、图片和链接。

插件不会读取账号、保存密钥或自动点击发布。平台是否提供官方投稿 API、授权条件和规则会变化；需要真正“自动发草稿”时，应只按相应平台的官方 API 单独接入。

## Edge 自动填充桥接

插件会在本机 `127.0.0.1:27124` 启动只读桥接。生成投稿包后，当前文章会在内存中保留 10 分钟；配套 Edge 扩展可读取标题和正文，并持续等待登录跳转或编辑器加载完成后自动填写。

- 数据不会上传到云端，桥接只监听本机回环地址。
- 只接受 Edge/Chrome 扩展来源的请求。
- 不读取 Cookie，不保存平台账号，不自动点击最终发布。
- 平台页面更新后选择器可能失效，此时仍可使用复制粘贴方式。

## 安装到本库

把此目录内的 `manifest.json` 与 `main.js` 放到库的 `.obsidian/plugins/multi-platform-publisher/`，重启 Obsidian 后在“设置 → 第三方插件”启用“多平台投稿助手”。

然后在 Edge 打开 `edge://extensions/`，启用“开发人员模式”，选择“加载解压缩的扩展”，指向项目的 `edge-extension/` 目录。
