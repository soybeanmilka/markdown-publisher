# 本地多平台投稿桥（Edge 扩展）

## 安装

1. 在 Edge 打开 `edge://extensions/`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本目录。
4. 把扩展固定到工具栏。

## 使用

1. 保持 Obsidian 开启，并打开准备投稿的文章。
2. 点击 Obsidian 左侧发送图标；它会生成投稿包并打开全部创作页。
3. 扩展会自动等待编辑器出现并填入标题、正文，不需要逐页点击扩展弹窗。
4. 检查正文、图片、封面、标签和格式，确认无误后自己点击发布。

如果自动填写没有触发，再打开扩展弹窗使用“仅重试当前页面”。

## 边界

- 扩展只从 `127.0.0.1:27124` 读取文章，不读取或保存网站 Cookie。
- 不自动点击发布，不规避验证码、登录、授权或平台限制。
- 各平台编辑器经常更新。自动填写失效时，可以继续使用 Obsidian 插件提供的复制功能，并更新 `content.js` 中相应平台的选择器。

遇到桥接 `403` 时，请同时重载 Obsidian 插件与 Edge 扩展，确保两边都升级到使用 `X-Local-Publisher-Bridge` 请求头的版本。
