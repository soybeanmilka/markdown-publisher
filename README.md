# Markdown 多平台发布器

这是一个本地、零依赖的小工具。它把一篇 Obsidian Markdown 生成公众号 HTML、知乎/小红书/今日头条/B站稿件和一张发布清单；不依赖或绕过任何付费插件。

## 第一步：准备一篇要发布的笔记

在笔记库的 `10-准备发布/` 中完成文章。首个一级标题会成为文章标题；开头的引用块（`> ...`）会成为摘要。

## 第二步：生成平台稿件

在 PowerShell 中运行：

```powershell
python publisher.py "E:\Desktop\obsidian\轻量化\10-准备发布\你的文章.md"
```

生成结果在本项目的 `output/你的文章名/`。这个目录不会被 Git 跟踪，避免把待发布内容误传。

## 第三步：发布

1. 双击 `公众号.html`，浏览器打开后选中**正文内容**并复制，粘贴到公众号编辑器。
2. 对知乎、小红书、B站，复制相应 `.md` 的正文。
3. 按 `发布清单.md` 最后检查标题、封面、链接和代码块，再发布。

## 微信公众号官方草稿 API

插件 `0.5.0` 开始支持“同步当前笔记到微信公众号草稿箱”：使用公众号自己的 AppID / AppSecret 获取令牌，把正文图片上传到微信图床、首图上传为永久封面素材，再调用官方 `draft/add` 创建草稿。正文由 Obsidian 原生渲染器生成，数学公式和 Mermaid SVG 会尽量转成 PNG，基础样式改为内联样式。

这项能力只适用于拥有对应 API 权限的公众号；个人主体、未认证或接口权限被回收的账号会收到微信返回的权限错误。AppSecret 保存在当前笔记库插件目录的 `data.json`，不要同步到公开 Git 仓库或发给他人。

## 为什么其它平台仍是“半自动”

各平台的自动发布需要各自的官方 API、企业/开发者资质或账号授权，而且规则会变化。先让内容转换和排版这部分完全本地化，能减少绝大多数重复劳动，也不会泄漏账号或密钥。后续如果某个平台的官方 API 条件满足，再单独接入该平台。

## 当前支持与边界

- 支持：YAML 属性移除、Obsidian 双链、Obsidian 本地图片嵌入、标题、引用、列表、行内代码、粗体、普通链接、代码块和基础表格。
- 需要人工检查：平台是否成功接收图片、封面、复杂公式、嵌套列表及平台特有卡片。

## Obsidian + Edge 自动填充版

项目现在还包含：

- `obsidian-plugin/`：生成投稿包，并在本机提供十分钟有效的文章桥接。
- `edge-extension/`：读取本机桥接，在公众号、小红书、知乎、今日头条和 B 站专栏创作页自动等待并填入标题与正文。

默认工作流已经压缩为一次点击：在 Obsidian 打开文章后点击左侧发送图标，其余创作页会自动打开并等待填写。

安装和使用步骤见 [Obsidian 插件说明](obsidian-plugin/README.md) 与 [Edge 扩展说明](edge-extension/README.md)。扩展不会读取 Cookie 或自动点击发布；本地图片会随富文本一起填入，但平台是否完成图片上传仍需检查，封面、标签和最终发布也由用户确认。

上游实现研究和许可证边界见 [源码调研](docs/upstream-implementation-research.md) 与 [第三方许可证通知](THIRD_PARTY_NOTICES.md)。
