# Markdown 多平台发布器

这是一个本地、零依赖的小工具。它把一篇 Obsidian Markdown 生成公众号 HTML、知乎/掘金/CSDN Markdown 和一张发布清单；不登录账号，也不依赖或绕过任何付费插件。

## 第一步：准备一篇要发布的笔记

在笔记库的 `10-准备发布/` 中完成文章。首个一级标题会成为文章标题；开头的引用块（`> ...`）会成为摘要。

## 第二步：生成平台稿件

在 PowerShell 中运行：

```powershell
python publisher.py "E:\Desktop\obsidian\轻量化\10-准备发布\你的文章.md"
```

生成结果在本项目的 `output/你的文章名/`。这个目录不会被 Git 跟踪，避免把待发布内容误传。

## 第三步：发布

1. 双击 `公众号.html`，浏览器打开后选中**正文内容**并复制，粘贴到公众号编辑器。
2. 对知乎、掘金、CSDN，复制相应 `.md` 的正文。
3. 按 `发布清单.md` 最后检查标题、封面、链接和代码块，再发布。

## 为什么是“半自动”

各平台的自动发布需要各自的官方 API、企业/开发者资质或账号授权，而且规则会变化。先让内容转换和排版这部分完全本地化，能减少绝大多数重复劳动，也不会泄漏账号或密钥。后续如果某个平台的官方 API 条件满足，再单独接入该平台。

## 当前支持与边界

- 支持：YAML 属性移除、Obsidian 双链转普通文本、标题、引用、三级以内标题、无序列表、行内代码、粗体、普通链接、代码块。
- 需要人工检查：图片嵌入、表格、复杂公式、嵌套列表及平台特有卡片。

## Obsidian + Edge 自动填充版

项目现在还包含：

- `obsidian-plugin/`：生成投稿包，并在本机提供十分钟有效的文章桥接。
- `edge-extension/`：读取本机桥接，在公众号、小红书、知乎、B站专栏和 CSDN 创作页自动等待并填入标题与正文。

默认工作流已经压缩为一次点击：在 Obsidian 打开文章后点击左侧发送图标，其余创作页会自动打开并等待填写。

安装和使用步骤见 [Obsidian 插件说明](obsidian-plugin/README.md) 与 [Edge 扩展说明](edge-extension/README.md)。扩展不会读取 Cookie 或自动点击发布；图片、封面、标签和最终发布需要人工确认。
